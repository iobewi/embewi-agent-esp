Embewi Agent

Réécrit uniquement ota_0 — sans toucher NVS ni otadata

Flashe le firmware directement depuis le navigateur (Chrome / Edge, via Web Serial) en connectant l'ESP32 en USB.

Ton navigateur ne supporte pas Web Serial — utilise Chrome ou Edge. Cette page doit être servie en HTTPS (ou localhost) pour installer le firmware.

Cette opération est une récupération ciblée de l'image agent dans ota_0. Si ESP Web Tools propose un effacement complet, choisissez de conserver les données afin de préserver NVS et otadata.

Servi localement par le conteneur de dev via http-server web -p 8080.
