Configuration verrouillée

La configuration matérielle de cet appareil a été verrouillée et ne peut plus être modifiée depuis cette page.

Pour la déverrouiller, réinstalle le firmware avec l'option « Erase » dans ESP Web Tools : cela efface toute la mémoire de l'appareil, y compris les identifiants Wi-Fi, et lève le verrouillage.
